- **Design notes:** `decode` throws on non-UTF-8 bytes (the editor shows "not UTF-8 text, edit it in another editor" and never writes); a file > 2 MB opens read-only (SD-s); an unedited save writes the original bytes back exactly (covers mixed line endings), an edited save re-applies the first line ending, BOM and trailing newline. Save is `Mod-s` through the `writeFile` prop (auto-save is E3.3). Task boxes toggle `[ ]`↔`[x]` on click. Wikilinks carry `data-wikilink=<target>`; the click → `onOpenLink` wiring is E3.2's criterion. The reading view also drops non-http(s)/mailto/relative link and image URLs (security; beyond the row's `<script>` minimum).
