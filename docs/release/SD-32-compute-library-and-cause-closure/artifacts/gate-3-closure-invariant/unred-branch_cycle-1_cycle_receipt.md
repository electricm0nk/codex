## Root cause

`origin/tranche/12` tip (`df771142c8`) was red:

```
cargo test --locked --test v06_work_inventory --no-fail-fast
FAILED: sd30_campaign_setting_books_appear_in_the_inventory_as_not_started_books
  inner_sea_faiths must be registered future_state, got String("in_scope")
```

`tests/v06_work_inventory.rs`'s `SD29_INGESTED_CAMPAIGN_SETTING_BOOKS` list (despite its name, the
roster of SD-30 campaign_setting books this test expects to already be `in_scope` rather than
`future_state`) did not include `inner_sea_faiths`/`inner_sea_magic`/`inner_sea_taverns`/
`inner_sea_temples`. Card 4's commit `a50b7da04c5fe35e622d26e58e5429ea2404d8ce`
("feat(sd32): onboard 4 unbuilt books' compiled rule sets (Gate 0 close)") landed a real,
non-fixture producer for all four books:

- `inner_sea_faiths`/`inner_sea_magic`/`inner_sea_temples` each get a real `spell` family via a new
  `rules_tables::<book>::spell_list` module generated by `ingest_inner_sea_setting_spells.rs`,
  chained into `spell_resolver::spell_catalog_rows()`.
- `inner_sea_taverns` gets a real `feat` family via the existing generalised
  `gen_feat_gap_tables.rs` generator.

All four gained their first entry in `COMPILED_RULE_SETS` (`src/bin/v06_work_inventory.rs`), which
is the sole input `rule_set_for()` reads to decide `scope: "in_scope"` vs `"future_state"`
(`src/bin/v06_work_inventory.rs` lines ~8927-8937). This flip is real content reaching the engine,
not a producer defect — confirmed by reading `a50b7da04`'s own diff and by `kanban.md` row 4's
closure summary (AT-32-G0-003, Gate 0 now closed).

**Disposition: (a) — the book genuinely is in scope now; the test assertion was stale.** Same
class of drift the sibling `t2b-refine-kind-fix` cycle hit for `inner_sea_temples` in
`rule_set_mapping_tests::uncompiled_books_stay_none` (that cycle's receipt,
`epic-2-t2b-refine-kind-fix_cycle-1_cycle_receipt.md` §7), except that fix retargeted a *different*
test to a still-uncompiled book (`guide_to_the_river_kingdoms`). This test cannot be retargeted the
same way: checking `COMPILED_RULE_SETS`/`corpus_dir_for` shows **all twelve**
`SD30_CAMPAIGN_SETTING_BOOKS` now carry a `RuleSetId` (`Botd1`, `Botd2`, `Iswg`, `Isc`,
`InnerSeaFaiths`, `Isg`, `InnerSeaMagic`, `Isr`, `InnerSeaTemples`, `InnerSeaTaverns`, `Isb`,
`Isi`) — there is no longer any book in this specific twelve-book list that is genuinely
`future_state`. The fix is therefore the same shape every prior addition to
`SD29_INGESTED_CAMPAIGN_SETTING_BOOKS` used (`inner_sea_races`, the two Book of the Damned
volumes, `inner_sea_combat`/`inner_sea_intrigue`, `inner_sea_world_guide`, `inner_sea_gods`): add
the four newly-ingested books to that list with a cited commit, rather than deleting or loosening
the assertion. The test still guards its real invariant — a book silently flipping `scope` (in
either direction) still fails it; the `else` branch (per-unit `not-started` checks for genuinely
un-ingested books) simply has no members left inside this particular twelve-book roster to
exercise, which is a true fact about SD-30's roster today, not a test that can no longer fail.
