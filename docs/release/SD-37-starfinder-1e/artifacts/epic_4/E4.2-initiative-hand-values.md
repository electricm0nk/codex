# SD-37 Starfinder seed initiative hand values (E4.2)

`seed-hand-values.md` (E0.4) carries no initiative row, and E4.2's criterion includes initiative.
These four rows follow that file's row shape (`| SF-<seed> | <field> | <value> | <SRD URL + section>
— <arithmetic> |`) and its source rule (`decisions.md §18`): the rule is transcribed from the
Starfinder Reference Document as hosted by Archives of Nethys, and the inputs (each seed's Dex
modifier) are the E0.4-reviewed ability tables in `../epic_0/seed-builds.md`.

**Rule.** "An initiative check is a d20 roll to which a character adds her Dexterity modifier plus
any other modifiers from feats, spells, and other effects."
(https://www.aonsrd.com/Rules.aspx?ID=96, Initiative, Starfinder Core Rulebook pg. 238; fetched
2026-10-03, HTTP 200, 24,152 bytes, sha256
`278e07eb953987081f99d76a29aecb7d6c0b1fab65e2ddd1fd12245f90111e0f`, fetched twice with the same
digest.)

**Other modifiers.** None of the seeds' feats, class features, racial traits or themes
(`seed-builds.md` §1–§4) modifies initiative: Weapon Focus, Quick Draw, Deadly Aim, Coordinated
Shot, Spell Penetration, Spell Focus and Mobility each modify something else. So each value is the
Dex modifier alone.
