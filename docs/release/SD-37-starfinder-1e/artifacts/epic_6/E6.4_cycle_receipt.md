## Does not cover

- **Transitive imports.** The "no `rules_tables`" check reads `sf_catalog.rs`'s own code. The library modules it calls (`sheet_rule_catalog`, `sheet_rule`) are shared with Pathfinder; `sheet_rule.rs` names `rules_tables` once, inside `CharacterFacts::from_character` (line ~1504), which the catalog never calls. The proof does not exercise linkage.
- **Kinds not catalogued.** Deities (39), languages (68), skills (116), templates (87), equipment modifiers (336), proficiencies and the other `ability` pools (class features 1,098, racial traits 605, archetypes 213, weapon rows 998 …) have no Starfinder catalog. They print on the sheet where a character holds them (E5). Counts: `find data/starfinder-1e/sheet_rules -type f | awk -F/ '{print $(NF-1)}' | sort | uniq -c` and the pool survey in this cycle (Python over `*/ability/*.json`). Only the six kinds the Pathfinder landing already offers an analogue for (plus themes and feats) are listed — logged as a safe default.
- **Pathfinder-only catalogs under Starfinder.** Monster, companion and intelligent-item catalogs are not offered for Starfinder (no Starfinder data for them; Starfinder companions/drones are E5.4 sheet content).
- **Rendering past 200 rows.** The frontend test renders the race (77) and class (11) responses in full. Feats (224), spells (370) and equipment (2,634) are rendered 200 at a time behind the search; their rows are proven by the Rust tests, not by a frontend render. The ui-smoke row opens the Classes tab only.
- **Book names.** A row's book is the package book id shown as words (`alien_archive_2` → `Alien Archive 2`, `core` → `Core`); there is no title registry for Starfinder books, so `Core` is not expanded to "Core Rulebook".
- **Prose quality.** A description is whatever the engine's catalog prose gives; races carry only their stat block (`Speed: Walk 30 ft.`) plus their total rows, because the converted race record has no authored prose. The rows' summaries are `catalog_field_summary`'s words, verbose for a class principal (class skills, declarations).
