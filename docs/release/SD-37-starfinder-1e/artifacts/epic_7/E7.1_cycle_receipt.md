### The cause of the per-weapon `+0` (E5.MC → E7.1)

Every Weapon Specialization raises `Damage_<group>` by `EffectiveLVL`. `EffectiveLVL` is set for every character by PCGen's global `Default` ability (`scr_abilities.lst:68`, `CATEGORY=Internal|Default.MOD DEFINE:EffectiveLVL|0 BONUS:VAR|EffectiveLVL|TL|TYPE=Base`; `Default` is granted unconditionally by the Strength row, `scr__stats.lst:4`). No SF population record stands for `Default`, so `mark_always_held` could not mark it and its `BONUS:VAR` rows were dropped (E4.2 had folded only its `DEFINE`s). `EffectiveLVL` was 0 on every character but a drone (the drone's own `BONUS:VAR|EffectiveLVL|DroneMasterLVL` survived). The converter now writes `Default` as ONE always-held record, `core:ability:default` (`print: false`, no target, no grants), whose variable declarations and unconditional contributions are the base state of every evaluation — the existing `SheetRule::always_held` semantics. Pathfinder is not touched (the code returns early for any system but Starfinder). After it: SF-Soldier-3's azimuth laser rifle damage bonus = 3 (oracle 3; SRD Weapon Specialization: character level).
