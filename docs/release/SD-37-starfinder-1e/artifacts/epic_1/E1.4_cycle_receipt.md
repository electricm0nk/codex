  `PF_SEED_RENDER_OUT=<dir> cargo test --locked -j 8 --bins pf_seed_render_hash -- --test-threads=8 --nocapture`
  → writes `<dir>/aldric.json`, `<dir>/elowen.json`, `<dir>/sha256.txt` (sha256sum format) and prints `pf-seed-render <seed> sha256=<h> bytes=<n>` plus `pf-seed-render manifest_dir=<crate dir>` (proves which tree the binary was built from).
