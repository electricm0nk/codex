## The table population ("every table")

`TABLE_IDS` = 279 tables = **A** + **B**:

- **A — 226 file-level `const`/`static` arrays** (predicate: an item at brace depth 0 of a `rules_tables/**.rs` file whose type is `[..]`, `&[..]` or `&'static [..]`). 222 are registered as themselves; the other 4 are registered under their own id as rows that can be read back: `ARG_CLASS_SPELL_LEVELS` (its inner slices as vectors, identical JSON), and the three registries over other tables — `MONSTER_BOOKS`, `COMPANION_BOOKS`, `STATIC_CLASS_SPELL_LISTS` — as index rows that name each referenced table by id (matched by content; `""` for an empty slice). Closed by `tests::every_file_level_array_is_a_package_table` (its own scanner, not this script's).
- **B — 53 tables that live in function bodies** (counted as the remaining `built` entries besides the 4 above): 7 `archetype_swap_tables()`, 7 inline `feat_tables()` (PU, UCA, UC, UI, UM, UPSI, UW), 5 inline equipment tables (PU; UE and UI `equipment_tables`/`equipmod_tables`), `eidolon_subtypes()`, `bestiary::cross_table_owner_names()`, Bestiary 1's 46 stat-block constructors as one table (`beastiary1/monster_resolve`, 46 rows = `MonsterId::ALL`), 20 class progression tables (CRB `class_tables()` + 19 `class_table()`), the Unchained class chassis (`class_chassis_resolve` over every class and level), 8 psionic base power-point ladders (`*_power_points_total(level, 0)`, levels 1–20), and the Unchained rogue and summoner feature ladders (`key`/`name`/`declaring_line`/`min_level` per `ALL` variant).
