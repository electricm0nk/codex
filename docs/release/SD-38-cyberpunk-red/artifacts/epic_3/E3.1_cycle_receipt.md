## What landed

- `preview_cyberpunk_character(request)` and `create_cyberpunk_character(request)` (`cpr_creation.rs`, final names = `technical-design.md §5` proposals). Request: `role`, `method` (`streetrat | edgerunner | completePackage`), `seed?` (u32), `templateRoll?` (Streetrat pick, 1–10), `stats?` (Complete Package allocation by STAT id).
- **Streetrat:** picked row, or one 1d10 drawn → the Role's whole template row (p074–p078). **Edgerunner:** ten 1d10, INT → EMP, each STAT read from its own column of the row its roll names (p078). **Complete Package:** sum must equal the corpus `complete_package_points` record marked `default` (62, p079); each STAT 2–8; a missing or unknown STAT id is a problem. Refusals are claim-blocking `problems` on preview and a `Blocked { diagnostics }` on create (nothing saved). Create also refuses an empty name and an id already saved.
- **Roller:** `CprRoller` — SplitMix64 over a u32 seed (exact through JSON), faces by rejection sampling. Preview returns `seed` and every die drawn (`rolls`); create with that seed draws the same dice. `pub(crate)` so Lifepath (E3.3) and HL dice reuse it.
- **Rows:** `explanations` = the engine's `cpr.stat.*` (`cpr::sheet::stat_rows`) + `cpr.derived.*` (`cpr::stats::derived_rows`, Humanity = EMP x 10 since no cyberware yet); nothing in `cpr_creation.rs` computes a sheet number. Complete Package also answers `statPointsSpent` / `statPointsTotal` (a creation figure, not a sheet value) so E3.2's allocator does not re-derive it.
- Create saves through `CprCharacterStore::save` and reads back through `rule_system_adapter::load_saved_character_via_envelope` (the summary returned is the loaded one).
- Boundary `apps/desktop/src/boundary/cprCreation.ts`: `previewCyberpunkCharacter`, `createCyberpunkCharacter` (same no-runtime error shape as `cprDeck.ts`).
