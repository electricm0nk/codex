## Every number on the loaded sheet = `compute_sheet` for the saved input

Method (`E3.MC/`): `capture.py` runs beside `run.mjs` and copies (a) each character directory from the isolated root before the
row's cleanup deletes it — the saved input the sheet was loaded from — and (b) the app's own UI probe snapshot (`bodyText` =
`innerText`) while the loaded sheet is on screen. `sheet_tool` (a standalone crate depending on `codex`) reads the saved directory
with the same calls the adapter makes (`CprCharacterStore::load`/`load_choices`/`load_lifepath`, `compose_sheet`, the desktop's
`cpr_sheet_print::sheet_lines` included by path) — independent of the running app. `compare.mts` renders the app's own
`CyberpunkCharacterSheet` over that answer with the corpus catalogs and compares, as **multisets of text lines**, with the live
sheet: **A** every computed table row (label + all cells) is on screen as often as expected; **B** no line holding a digit is on
screen more often than expected (no number compute_sheet did not give); **C** every rendered `data-cpr-row` cell = its
explanation row's value.

Commands: `cd docs/.../E3.MC/sheet_tool && CARGO_TARGET_DIR=/home/ubuntu/cargo-target/sd38-e3/mc-tool cargo build --release`;
`e3mc_sheet_tool <saved dir> data/cyberpunk-red/corpus apps/desktop/src/characterHub/__tests__/cyberpunkSheetFixtures/cpr-solo-kitted.json <expected.json>`;
`cd apps/desktop && npx tsx <E3.MC>/compare.mts <expected.json> <probe.json> <report.json>` (`green/compare.txt`, `green/report-*.json`):

| Character | compute_sheet rows | printed lines | A computed rows on live sheet | B live digit lines from compute_sheet | C cells = row |
|---|---|---|---|---|---|
| CPR MC Streetrat Media | 212 | 38 | 114 / 114 | 130 / 130 | 212 / 212 |
| CPR MC Edgerunner Netrunner | 214 | 41 | 115 / 115 | 131 / 131 | 214 / 214 |

Second implementations: the live digit-line counts re-counted in Python straight from `green/live-sheet-*.txt` (from the sheet
heading to the end, lines matching `\d`) → 130 / 131 / 120, equal to B's denominators. `crosscheck.py` (Python, the book's

`green/crosscheck.txt`). The Edgerunner's saved STATs 5 8 6 6 7 3 7 7 5 6 are each a value of their Netrunner template column:
10 of 10 (`green/edgerunner-columns.txt`). The saved input files and the live sheet text are committed (`green/saved/*`,
`green/live-sheet-*.txt`), so A/B/C re-run without the app.
