normalised text similarity (`difflib.SequenceMatcher` ratio over lowercased, non-alnum-
stripped label text) between each newly-added LINE's label and (a) every OTHER already-
printed LINE of the same `kind` in the same build, (b) every EXPL id's own tail words (the
EXPL id's namespace/`corpus_record` segments stripped, mirroring 3b.2's corrected R2 spec)
in the same build. Threshold 0.82 (tuned so the two known-good near-miss labels the epic
doc itself names as legitimate non-duplicates -- `fighter_bravery`/`fighter_armor_training`
style distinct-feature pairs -- do not collide, while `"Uncanny Dodge"` vs `"... Uncanny
Dodge Tracker"` and `"Aura of Righteousness"` do). Every hit is listed as SUSPECTED --
