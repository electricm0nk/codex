## Update (v0.6 alpha swarm, risks item 8, Arcanist full-build closure, first non-CRB class attempting real `Computed` status, 2026-07-25)

Arcanist's own chassis-integration gate (`is_supported_arcanist_single_class` in `pilot_compute.rs`) is now genuinely wired -- the fifth widening of `has_supported_class_chassis` to an ACG/APG class, and the first to build REAL spellcasting from scratch (every prior closure this session either deferred spellcasting entirely or reused an already-built table byte-for-byte). Grounds: the Arcane Reservoir (a flat, choice-free daily resource pool -- max `3+level`, daily fill `3+level/2`, no `class_ability_activations` entry needed at all); and a genuine prepared-spellbook posture (`ground_or_block_arcanist_class_features`/`unmet_arcanist_spellbook_conditions`/`ground_arcanist_prepared_spellbook`, mirroring `unmet_wizard_spellbook_conditions`'s own shape minus the opposed-school mechanic Arcanist doesn't have). Arcanist's own spells-per-day table (`arcanist_base_spells_per_day`) is a genuinely independent, own table -- verified via two sources (the raw corpus `BONUS:VAR` formulas hand-evaluated at levels 1-5, and legacy.aonprd.com's own printed "Table: Arcanist Spells Prepared") that agree exactly with each other but NOT with Wizard's own table (Arcanist level 1: 4 cantrips/2 first-level vs Wizard's 3/1; Arcanist's own 2nd-level spells unlock at level 4, not Wizard's level 3), even though the spell-list CONTENT and casting SHAPE (prepared, spellbook-gated, `SPELLLIST:1|Wizard`) are genuinely shared. Class-skill wiring needed zero new code: Arcanist's own class-skill list (Appraise, Craft, Fly, Knowledge, Linguistics, Profession, Spellcraft, Use Magic Device) includes none of the three skills `compute_selected_skill_modifiers` tracks (Climb/Intimidate/Swim), so the existing generic mechanism already produces the correct (no-bonus) answer, the same shape as Wizard's own. Arcanist still does not reach `Computed` for a bare/no-spells posture -- the new, narrower `class_feature.acg.arcanist.exploits_deferred.unsupported` diagnostic (replacing the generic `class_feature.acg.arcanist.unsupported`) names Arcanist Exploits/Greater Arcanist Exploits (a chooser-list), Consume Spells, and Magical Supremacy as the genuinely still-missing pieces, and an empty spellbook is a genuine (if incomplete) posture mirroring Wizard's own pre-bootstrap-fix shape -- a real product-reachability path needs its own separate `compose_character_input` seeding follow-on, the same two-cycle shape Wizard's own history had. See `docs/release/v0.6/arcanist-acg-full-build-scoping.md` and `full-class-build-comparative-scoping.md` for the full corpus verification and scope record, and `pilot_compute.rs`'s `arcanist_dispatch_widening_safety_tests` module for the full test coverage.
