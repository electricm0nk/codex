## Update (v0.6 alpha swarm, risks item 8, Arcanist full-build closure, first non-CRB class attempting real `Computed` status, 2026-07-25)

Arcanist's own chassis-integration gate (`is_supported_arcanist_single_class` in `pilot_compute.rs`) is now genuinely wired -- the fifth widening of `has_supported_class_chassis` to an ACG/APG class, and the first to build REAL spellcasting from scratch (every prior closure this session either deferred spellcasting entirely or reused an already-built table byte-for-byte). Grounds: the Arcane Reservoir (a flat, choice-free daily resource pool -- max `3+level`, daily fill `3+level/2`, no `class_ability_activations` entry needed at all); and a genuine prepared-spellbook posture (`ground_or_block_arcanist_class_features`/`unmet_arcanist_spellbook_conditions`/`ground_arcanist_prepared_spellbook`, mirroring `unmet_wizard_spellbook_conditions`'s own shape minus the opposed-school mechanic Arcanist doesn't have). Arcanist's own spells-per-day table (`arcanist_base_spells_per_day`) is a genuinely independent, own table -- verified via two sources (the raw corpus `BONUS:VAR` formulas hand-evaluated at levels 1-5, and legacy.aonprd.com's own printed "Table: Arcanist Spells Prepared") that agree exactly with each other but NOT with Wizard's own table (Arcanist level 1: 4 cantrips/2 first-level vs Wizard's 3/1; Arcanist's own 2nd-level spells unlock at level 4, not Wizard's level 3), even though the spell-list CONTENT and casting SHAPE (prepared, spellbook-gated, `SPELLLIST:1|Wizard`) are genuinely shared. Class-skill wiring needed zero new code: Arcanist's own class-skill list (Appraise, Craft, Fly, Knowledge, Linguistics, Profession, Spellcraft, Use Magic Device) includes none of the three skills `compute_selected_skill_modifiers` tracks (Climb/Intimidate/Swim), so the existing generic mechanism already produces the correct (no-bonus) answer, the same shape as Wizard's own. Arcanist still does not reach `Computed` for a bare/no-spells posture -- the new, narrower `class_feature.acg.arcanist.exploits_deferred.unsupported` diagnostic (replacing the generic `class_feature.acg.arcanist.unsupported`) names Arcanist Exploits/Greater Arcanist Exploits (a chooser-list), Consume Spells, and Magical Supremacy as the genuinely still-missing pieces, and an empty spellbook is a genuine (if incomplete) posture mirroring Wizard's own pre-bootstrap-fix shape -- a real product-reachability path needs its own separate `compose_character_input` seeding follow-on, the same two-cycle shape Wizard's own history had. See `docs/release/v0.6/arcanist-acg-full-build-scoping.md` and `full-class-build-comparative-scoping.md` for the full corpus verification and scope record, and `pilot_compute.rs`'s `arcanist_dispatch_widening_safety_tests` module for the full test coverage.

Keeping the "count real distinct KEY records with genuine, SEPARATELY-implemented backing logic" methodology consistent across classes rather than letting it drift per-class.

## Update (v0.6 alpha swarm, risks item 8, Arcanist Metamagic Knowledge Exploit closure, 2026-07-25) — first ACG/APG class to reach real `Computed`

Of Arcanist's 46 real `KEY:Arcanist Exploit ~ ...` sub-list records (a chooser-list layer under the single `Arcanist Exploits` feature slot already counted above -- the same "floor, not ceiling" sub-list exclusion this doc's own `named_features_expected` methodology already applies to Destruction Blessing's own record under Warpriest's single `Blessings` slot), Metamagic Knowledge is genuinely different from the other 45: verified directly against its own raw corpus record, it carries no `BONUS:VAR` reservoir-cost tag at all (uses `BONUS:ABILITYPOOL` instead) -- a one-time bonus-feat grant, not an activation-gated, Reservoir-consuming ability. `ground_or_block_arcanist_metamagic_knowledge` (`pilot_compute.rs`) recognizes a `choice:arcanist_metamagic_knowledge` selection and validates it via `feat_prereqs::metamagic::evaluate_metamagic_feat_prerequisites`/`resolve_metamagic_feat_effect` -- genuine reuse of an already-built, already-tested module from an earlier, unrelated SD-20 Epic 3 cycle, not new validation logic. Deliberately recognizes ANY real, catalog-verified CRB Metamagic feat (not hardcoded to one literal): the reused module validates every Metamagic feat with equal confidence, so artificially restricting to `Empower Spell` alone would be a narrower, less honest claim than what the module already proves. `Empower Spell` is this closure's own proven canonical test example (confirmed to carry zero `PREREQ:` token in `cr_feats.lst`, like every other CRB Metamagic feat).

Confirmed before building (independently re-verified by team-lead): `push_arcanist_exploits_deferred_diagnostic` was the ONLY claim-blocking diagnostic left once a valid spellbook posture existed. Recognizing Metamagic Knowledge replaces that claim-blocking diagnostic with a non-blocking note (naming the other 45 Exploits, Greater Exploits, Consume Spells, and Magical Supremacy as still deferred) -- so an Arcanist with a real, valid spellbook AND a recognized Metamagic Knowledge choice now reaches genuine `HeadlessReceiptStatus::Computed` in a headless test fixture (`single_class_arcanist_with_a_valid_spellbook_and_recognized_metamagic_knowledge_reaches_computed`), **the first ACG/APG class this segment to do so**. This does NOT bump `named_features_wired` (Metamagic Knowledge is a sub-list entry under the already-counted `Arcanist Exploits` slot, mirroring Destruction Blessing's own non-bump for Warpriest).

**This is explicitly NOT the same as product-reachability.** No picker exists in the real character-creation UI for `choice:arcanist_metamagic_knowledge` either -- the same Path A gap Sorcerer/Cleric/Druid/Wizard's own `compose_character_input` seeding closed for THEM specifically. A genuine product-reachable Arcanist would need its own separate `compose_character_input` seeding follow-on (seeding both the starter spell AND a canonical Metamagic Knowledge choice), not assumed free here -- keeping the "engine reaches Computed" vs. "product is reachable" distinction honest, the same discipline this whole segment has used throughout. See `docs/release/v0.6/arcanist-metamagic-knowledge-exploit-scoping.md` for the full record.
